3. EXPAND FEATURE BOUNDS
==================================================

Create a reusable helper that expands trustworthy geocoder bounds geographically before calling fitBounds.

The expanded frame should include:

- whole site/building

- nearest useful junctions
- neighbouring buildings

Do not use Amazon-specific logic.

For already large bounds:
expand proportionally LESS.

small feature bounds

large feature bounds
→ expand moderately

The expansion should be based on geographic span, not project/company names.
