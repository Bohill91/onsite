==================================================

2. USE A STRONGER DEFAULT ZOOM
==================================================

Current zoom is still effectively too wide.

For a precise geocoded site/building coordinate, target approximately:

zoom 17.4–17.7

For a less precise street-level geocode:

approximately 17.0–17.3

For an already saved exact entrance:

approximately 17.6

Choose values that work correctly in the current provider.

At desktop width, the map should generally show roughly the immediate site area / surrounding few hundred metres, NOT several kilometres.

Do not automatically reset zoom after the user manually changes it.

==================================================

The current map is still too washed out.

Create clear but tasteful separation between:

LAND
BUILDINGS
ROADS
GREEN SPACE
WATER
RAIL
LABELS

4. LAND
==================================================

Make general land a clean warm off-white/light neutral.

Target visual family roughly equivalent to:

#F5F5F2

==================================================
5. BUILDINGS — MAKE THEM CLEARLY READABLE
==================================================

Current buildings still blend too much into the background.

Make building footprints visibly darker than land.

Target visual family roughly equivalent to:

#D8D9D6 to #DDDEDA

A user should be able to look at the map and instantly see:

"that is the building"

without zooming further.

Do NOT make buildings dark or brown.

==================================================
6. ACCESS ROADS — MUCH CLEARER
==================================================

This is an entrance picker, so access roads are critical.

Local/access roads should be:

- white or near-white
- clearly separated from surrounding land
- have a subtle neutral casing/edge

Target road fill:
approximately #FFFFFF

Target casing family:
approximately #D7D9D7

Make access roads meaningfully more visible than they are now.

Do NOT use yellow/orange road fills.

==================================================

Use obvious hierarchy:

Small/local access road
→ crisp white, restrained casing

Normal road
→ slightly stronger/wider

Major road
→ clearly identifiable but still neutral

Do NOT let major roads dominate the whole map.

==================================================

==================================================

Current labels are still too faint.

- road names

Do not make every POI prominent.
