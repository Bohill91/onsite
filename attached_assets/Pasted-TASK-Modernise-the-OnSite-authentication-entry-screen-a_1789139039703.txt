This is a VISUAL / UX POLISH task only.

Do NOT change authentication logic.

==================================================
GOAL
==================================================

The current auth pages are visibly from the old OnSite design.

Problems include:

- oversized centred OnSite logo
- oversized header
- too much unused vertical space
- old spacing and proportions
- login page feels disconnected from the current app
- Back button feels detached from the layout
- orange CTA is visually too heavy
- weak hierarchy around supporting links
- old grey/background treatment
- inconsistent component styling
- the welcome page currently says:
  "Join thousands of verified tradespeople and companies already using OnSite."
  which does not match the current OnSite positioning

Bring these screens into the same visual family as the new:

- Dashboard
- Projects
- Request Labour
- Project Detail

Use the same restrained OnSite design language:

- clean white / very light grey
- black typography
- orange #F97316 accent
- neutral borders
- restrained shadows
- no gradients
- no glass effects
- no oversized branding
- strong spacing and hierarchy
- modern Stripe / Linear / Ramp-style restraint

==================================================
1. REDESIGN THE SHARED AUTH HEADER
==================================================

The current Login header has:

- giant centred OnSite logo
- Back button floating on the left
- excessive header height

Replace this with a compact shared auth header.

Desktop target:

- approximately 64–72px tall
- white background
- subtle bottom border
- content aligned to the same overall page width/grid
- OnSite wordmark significantly smaller
- wordmark should feel like navigation branding, NOT the hero content
- Back action positioned cleanly within the same header layout when required

Preferred structure:

[ Back ]        [ compact OnSite wordmark ]

or another balanced implementation that keeps the wordmark visually centred without needing a giant logo.

Do NOT make the header feel like a marketing website navbar.

No extra navigation links.

The header should be reusable by:

- Welcome/account choice
- Login
- Register
- Forgot Password

even if only the first two are visually updated in this task.
