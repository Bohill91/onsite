1. DEFAULT OPENING ZOOM / VIEWPORT
==================================================

The biggest remaining issue is the opening viewport.

Current behaviour can land at two bad extremes:

TOO CLOSE:
- building fills most of map
- surrounding access context is lost

TOO FAR:
- large surrounding districts / major landmarks become visible
- no longer feels like an exact entrance selector

The default entrance-map view should normally show:

- the target site/building
- its immediate site/access roads
- adjacent junctions
- nearby surrounding buildings where useful
- enough context to identify which gate/entrance is correct

but NOT several kilometres of surrounding area.

Tune the vector-map default to approximately the equivalent of zoom 16.5–17.25.

Choose the actual provider-specific value based on visual results.

Do NOT hard-code Amazon/Wembley.

Use the selected site's real coordinates.

If the user already has a saved entrance and clicks Edit entrance:
centre on the saved entrance at an appropriate close zoom.
